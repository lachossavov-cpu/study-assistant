# Тестове

```bash
python tests/run_tests.py                # всичко
python tests/run_tests.py --no-network   # без edge-tts (когато няма интернет)
```

Пуска се срещу **временно копие** на базата — `AVANS_DB` сочи в temp папка, а един от
тестовете изрично проверява, че `data/tasks.json` не е бил докоснат.

## Какво покрива (94 теста)

| Област | Проверява |
|---|---|
| `tasks.py` | upsert пази моите полета, обновява извлечените, води история, маркира изчезнали; подредба по приоритет; парсване на дати; валидация на статуси; `localize()` |
| `brief.py` | двата езика дават различен текст, EN е без кирилица, заглавията не се превеждат, 12- срещу 24-часов формат, поздрав по час, празна база |
| `speak.py` | чистене на markdown, цепене без загуба на знаци, валиден MP3 от edge-tts |
| икони | PNG магия и размери, ICO с няколко резолюции, manifest сочи съществуващи файлове |
| HTTP | всички ендпойнти, `?lang=`, кодове за грешка, content-type на manifest-а |
| гласови команди | всеки интент на английски и на български; отговорът е на поискания език |
| сигурност | path traversal в `/audio`, неясна команда не затваря задача, изолация от истинската база |
| стартери | `JARVIS.bat` ползва 127.0.0.1; `install-autostart.ps1` е ASCII и ползва pythonw |

## Регресионни тестове, писани заради истински бъгове

- **`install-autostart.ps1` е само ASCII.** Windows PowerShell 5.1 чете `.ps1` като ANSI,
  ако няма UTF-8 BOM. Кирилицата вътре ставаше на боклук и парсерът отказваше — скриптът
  не работеше изобщо.
- **Сървърът тръгва през `pythonw` без конзола.** Без конзола първият запис в `sys.stdout`
  убиваше процеса с код 1 и без traceback. Автостартът мълчеше. Поправката е
  `_detach_logs()` в `server/app.py`, която пренасочва в `reports/server.log`.
- **Цепенето на текст не губи нито един знак.** Старото `sent[:size]` изхвърляше остатъка
  на всяко изречение по-дълго от лимита — при 4500 знака се губеха 1700. Цели пасажи
  никога не се изговаряха.
- **Неясна гласова команда не затваря грешна задача.** „done with absolutely nothing like
  that" затваряше „Reading with no deadline", защото двете споделяха думата „with", а
  размитото сходство добавяше останалото. Сега се иска покритие на отличителни думи
  от заглавието.
- **Заглавията остават непреведени** на всеки език — иначе не се намират в Brightspace.
- **Сървърът винаги пише в лог файл.** Когато имаше конзола, нищо не влизаше във файла —
  сървърът падна веднъж и не остави абсолютно никаква следа, така че причината остана
  неизвестна. Сега `start` без `stop` означава срив.
- **Промптът за прехвърляне е винаги на английски**, дори когато интерфейсът е български —
  преводът не бива да се промъква в заданието.

Говорът се сериализира в браузъра (`stopSpeech`, `AbortController`, второто натискане
спира вместо да рестартира) — това се проверява в браузър, не тук.

## Какво НЕ покрива

Фронтендът — DOM, пръстенът, микрофонът, офлайн банерът, превключвателят на езика.
Те искат истински браузър и се проверяват през браузър агент. Последната пълна проверка:
рендиране и съвпадение с API-то, дъгата на пръстена срещу оставащите дни (36% при 8.9 от
14 дни), разгъване на карти, смяна на статус от бутон, `en-US` → `bg-BG` разпознаване при
превключване, преведени полета с непреведено заглавие, запомнен избор в `localStorage`,
аудио от бутона Репорт, офлайн банер, и нула хоризонтално преливане при
320 / 375 / 768 / 1360 пиксела.
